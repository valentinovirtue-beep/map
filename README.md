# 桜木町36分圏 ワンルーム 総額6万円以下 物件一覧

横浜・桜木町駅まで36分圏内で、**総額（家賃＋管理費）6万円以下・ワンルーム・3階以上**の条件に合う部屋を集めた一覧ページです。
横浜側に加えて東京方面（川崎市・東京23区側）も調査し、107駅を全数調査して条件に合う524室を掲載しています。
治安データ（区ごとの犯罪率）と設備フィルタ（バストイレ別・オートロック・エアコンなど）も一緒に使えます。

## ページを見る

**➡ https://valentinovirtue-beep.github.io/map/**

上のリンクを開くだけで見られます。スマホでもパソコンでも大丈夫です。
アプリのインストールやログインは必要ありません。

## 載っている内容

- 路線図で見る物件の分布（南方面・北方面＝東京方面の10路線列）
- 駅別サマリ（条件に合う部屋数と最安家賃、カッコ内は区の犯罪率）
- 物件ごとの詳細一覧（家賃・総額・面積・築年・駅徒歩・桜木町までの時間・設備など）
- 設備での絞り込み（バストイレ別／オートロック／エアコン／洗濯機置場／洗面台／モニタホン／宅配BOX／都市ガス／システムキッチン／IH／ガスコンロ可）
- 読むときの注意

## 出典・注意

- 調査日: 2026年8月20日
- 物件: Yahoo!不動産（掲載物件）
- 治安データ:
  - 横浜市・川崎市: 神奈川県警「刑法犯 罪名別 市区町村別 認知件数」令和7年12月末確定値
  - 東京23区: 警視庁「区市町村の町丁別、罪種別及び手口別認知件数」令和7年（年計）
  - 犯罪率（‰）は認知件数を各自治体公表の人口（令和8年1月前後）で割った値。神奈川と東京で集計基準が完全に同一ではない点、東京都区部は昼間人口の影響で住民あたりの数値が高く出やすい点に注意
- 所要時間は乗換・待ち時間込みの概算（±5分程度のブレあり）
- 設備情報はYahoo!不動産の設備表記に基づくため、記載漏れがあり得ます。コンロの口数は掲載がないため、システムキッチン・ガスコンロ可・IHで代用しています
- 掲載状況は日々変動します。実際に空いているかは各不動産サイトでご確認ください
