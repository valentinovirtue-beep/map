# 桜木町30分圏 ワンルーム 総額6万円以下 物件一覧

横浜・桜木町駅まで30分圏内で、**総額（家賃＋管理費）6万円以下・ワンルーム・3階以上**の条件に合う部屋を集めた一覧ページです。
46駅を全数調査して、条件に合う290室を掲載しています。治安データ（区ごとの犯罪率）も一緒に見られます。

## ページを見る

**➡ https://valentinovirtue-beep.github.io/map/**

上のリンクを開くだけで見られます。スマホでもパソコンでも大丈夫です。
アプリのインストールやログインは必要ありません。

## 載っている内容

- 路線図で見る物件の分布
- 駅別サマリ（条件に合う部屋数と最安家賃、カッコ内は区の犯罪率）
- 物件ごとの詳細一覧（家賃・総額・面積・築年・駅徒歩・桜木町までの時間など）
- 読むときの注意
